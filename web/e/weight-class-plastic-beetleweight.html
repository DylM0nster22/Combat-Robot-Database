Plastic Beetleweight

The 3 lb equivalent of plastic antweight: robots must be built almost entirely from approved 3D-printable plastics rather than metal. Less common than plastic antweight but growing at the same regional US events that run plastic-only brackets.

Weight classplastic-beetleweight3d-printedlow-cost

Notes

Uses the same allowed-material list as plastic antweight (PLA, PLA+, ABS, PETG, ASA, PET; no TPU, nylon, or fiber-filled composites).
