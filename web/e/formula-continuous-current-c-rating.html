Continuous / Burst Current from Capacity and C Rating

The standard way manufacturers express a pack's maximum discharge current, and the calculation an antweight builder should run backward — from an estimated real current draw — to check whether a candidate pack's C rating is remotely credible.

Formulac-ratingcurrentsizing

Expression

Max_Current_A = (Capacity_mAh / 1000) * C_rating

Variables

Max_Current_Amaximum current the pack is rated to supply, amps
Capacity_mAhrated capacity in milliamp-hours
C_ratingmanufacturer discharge rating (continuous, and separately burst if given)

Worked example

A CNHL MiniStar 3S 450mAh 70C pack: (450/1000) * 70 = 31.5A claimed continuous. A realistic antweight rule of thumb (see chunk-c-rating-marketing-vs-reality) is to only trust roughly 40-60% of a budget/unknown pack's printed C rating for sustained draw, so a safer planning number for this pack is about 13-19A continuous, which is still comfortably above what a typical antweight drive+weapon combo pulls in steady state (see formula-power-budget-drive-weapon).
