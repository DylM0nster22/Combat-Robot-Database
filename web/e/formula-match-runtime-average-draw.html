Match Runtime from Average Current Draw

Estimates how long a pack will last in a match given an average (not peak) current draw across drive and weapon combined, used to size capacity against the standard 3-minute combat robotics match length.

Formularuntimepower-budgetmatch-length

Expression

Runtime_min = (Capacity_mAh / Average_Current_mA) * 60

Variables

Runtime_minestimated run time at the given average draw, minutes
Capacity_mAhusable pack capacity in mAh (using rated capacity is optimistic; treat only ~80% of rated capacity as safely usable before voltage drops too far)
Average_Current_mAaverage combined drive+weapon current draw over the match, milliamps

Worked example

A 3S 450mAh pack (using 80% = 360mAh usable) against an estimated average combined draw of 6A (6000mA) for a moderately aggressive antweight spinner+drive combo: Runtime = (360/6000) * 60 = 3.6 minutes — enough margin over a standard 3-minute match, but not by much, which is why builders round capacity up 25-50% over the bare computed minimum (see chunk-power-budget-current-draw-estimate).
