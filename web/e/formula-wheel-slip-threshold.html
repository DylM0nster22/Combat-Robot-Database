Wheel-slip threshold and the resulting real acceleration

Compares the torque-limited drive force against the traction-limited force to determine which one actually governs, then computes the robot's real (traction-limited) acceleration -- the number that matters for a 1 lb robot, which is almost always far below the torque-limited number.

Formulaantweightplastic-antweightdrivetraintractionacceleration

Expression

if F_drive > F_max: a_real = F_max / m_robot (traction-limited) ; else: a_real = F_drive_total / m_robot (torque-limited)

Variables

F_drivetotal force the drivetrain could deliver from torque alone, N
F_maxmaximum traction force available, N
a_realactual achievable acceleration, m/s^2
m_robottotal robot mass, kg

Worked example

F_drive (total, both wheels) = 20.0 N, F_max = 3.56 N. Since 20.0 N > 3.56 N, the drivetrain is traction-limited: a_real = F_max / m_robot = 3.56 / 0.454 = 7.85 m/s^2 -- roughly 0.8g, reached almost instantly since there is huge spare motor torque behind it. This also means a lighter/higher-torque motor swap would do nothing for straight-line acceleration here; better wheels/tires (higher mu) would.
