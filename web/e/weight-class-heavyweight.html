Heavyweight (220-250 lb)

The top-tier 'TV weight' class. BattleBots' modern single division caps at 250 lb (113 kg) ready-to-fight, while SPARC's traditional heavyweight class is 220 lb (100 kg); RoboGames also runs a 250 lb class plus a heavier walking-bonus tier. These robots require professional-grade fabrication, hydraulics/large brushless weapons, and are only run at events with heavy-duty arenas.

Notes

Exact heavyweight cap differs by organization: BattleBots = 250 lb (500 lb if a qualifying walker), classic SPARC heavyweight = 220 lb, RoboGames runs both a 250 lb class and a 500 lb walking-bonus tier. Always check the specific event's rulebook rather than assuming one universal 'heavyweight' number.
