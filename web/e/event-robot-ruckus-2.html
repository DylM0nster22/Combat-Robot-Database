Robot Ruckus

A US SPARC-compliant combat robotics event run in conjunction with Maker Faire Orlando, popular with antweight and plastic-antweight builders. Insect weight classes (fairyweight/antweight/beetleweight) run double-elimination, while the larger 12lb/30lb/30lb-super-class divisions use a pools/Swiss fight format instead.
