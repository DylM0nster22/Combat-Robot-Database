Walker/Non-Wheeled Weight Bonus

A weight allowance given to robots that move without continuous rolling or cam-driven contact with the floor, since true walking mechanisms are heavier and less efficient than wheels for a given weight. Typical bonus is +100% (double weight) for a full walker and roughly +50% for shufflers/other non-wheeled-but-not-strict-walker locomotion.

Notes

SPARC: 100% bonus for true walkers, up to 50% for shufflers. NHRL: True Walker = +100% (e.g. 3lb class robot may weigh 6lb); Non-Traditional Locomotion = +50% (e.g. 3lb class robot may weigh 4.5lb). RoboGames: walking-bonus classes are exactly double the regular class weight (150g->300g, 1lb->2lb, 3lb->6lb, 120lb->240lb, 250lb->500lb). AWS (UK): non-roller antweight bonus is 50% (150g->225g).
