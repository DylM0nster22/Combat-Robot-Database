Tipping-moment threshold for a 1 lb chassis

A first-order estimate of how much overturning moment a lightweight chassis can resist before it starts to lift/rock about the edge of its wheel track, using just weight and half the track width. It ignores CG height (a more complete model also uses formula-cg-tipping-angle), but is a fast way to check a precession torque against a real robot.

Formulaantweightplastic-antweightgyroscopictippingchassis-stability

Expression

M_tip = W * (track_width / 2)

Variables

M_tipapproximate moment needed to lift the chassis about one side's wheel line, N*m
Wrobot weight, N (= mass_kg * 9.81)
track_widthside-to-side distance between the drive wheels' contact patches, m

Worked example

A 454 g (0.454 kg) antweight has W = 0.454 9.81 = 4.453 N, track_width = 0.090 m (90 mm). M_tip = 4.453 (0.090/2) = 4.453 0.045 = 0.2004 Nm. Compare this to the 0.2042 N*m precession torque computed in formula-gyroscopic-precession-torque for the same robot: the precession torque slightly EXCEEDS the tipping threshold -- this robot would start to rock/tip if the driver spun it that fast while the weapon was at full speed. This is exactly the 'gyro dance' effect vertical-spinner drivers are warned about.

Notes

A simplified planar moment-balance estimate; real tipping also depends on CG height and suspension compliance.
