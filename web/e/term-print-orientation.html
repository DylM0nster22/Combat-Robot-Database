Print Orientation

Which way up a part is printed, which sets where its weak axis lies.

Termantweightplastic-antweightfabrication

Notes

Choose orientation by asking where the load goes. A wedge should be printed so impacts push layers together, not peel them apart. A bracket carrying a bolt should have the layers running across the bolt axis so the bolt does not split the part along a layer line. When a part has two conflicting load paths, either split it into two parts printed differently and bolt them together, or accept the weaker axis and add material there.
