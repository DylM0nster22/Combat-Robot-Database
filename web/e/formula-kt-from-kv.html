Torque constant Kt from velocity constant Kv (exact form AND common hobby shorthand)

Kv (rpm per volt of back-EMF) and Kt (torque per amp) describe the same physical motor constant in different units. The EXACT, physically-derived relation is Kt[N*m/A] = 60 / (2*pi*Kv[rpm/V]) = 9.5493 / Kv. The widely-used HOBBY SHORTHAND Kt = 8.27 / Kv is NOT the same physical law -- it silently bakes in an assumed ~87% mechanical/electrical efficiency (8.27/9.5493 = 0.866), so it already includes a loss derating. Use the exact 9.5493 form for real torque/spin-up physics, and only use 8.27 if you specifically want a quick 'expected real-world output torque' guess and are not also applying a separate efficiency factor on top of it.

Worked example

A small antweight weapon brushless motor is rated Kv = 2750 rpm/V. Kt_exact = 9.5493 / 2750 = 0.003472 Nm/A. Kt_hobby_shorthand = 8.27 / 2750 = 0.003007 Nm/A. The hobby value is 0.003007 / 0.003472 = 86.6% of the exact value, matching the ~87% efficiency it bakes in. All other worked examples on this page use the EXACT form (9.5493/Kv) for Kt.
