SPARC Plastic Class (Robot Construction Specifications v1.6, §16.3)

The template ruleset most North American plastic-ant events build from. Defines the class's spirit, the exact allowed plastics list (verified verbatim against the current v1.6 PDF, 21 September 2025), the COTS-parts exemption with explicit permitted/not-permitted examples, and a notably strict post-processing ban.

Notes

This is the single most copy-pasted plastic-ant ruleset in the US; SCAR, Robot Ruckus and many one-off regional events either quote it directly or diverge from it in a clearly marked 'deviations' section per SPARC's own template instructions (§2). Notably, SPARC's own §16.3.4 explicitly BANS annealing/acetone-smoothing/boiling as illegal 'durability-enhancing' post-processing — a direct, verified contradiction with SCAR's separate Plastic Ant FAQ, which explicitly ALLOWS annealing and acid smoothing. This is real, current org-to-org variation, not a hypothetical: a part legally annealed for a SCAR event would need to be reprinted un-annealed to be legal at a strict-SPARC event, and vice versa is a non-issue since SPARC's list is the stricter one.
